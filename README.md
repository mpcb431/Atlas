# Unicode Studio — 33 Collections

Persian/English Unicode typography and icons PWA.

## Features

26 styled Latin alphabets, 7 icon sets, RAU arrow collection, geometric symbols, superscript/subscript preview, supported native digits, and persistent personal favorites using localStorage. No tracking or backend.

## iPhone installation

After GitHub Pages is enabled on this branch, open the HTTPS site using Safari, use Share → Add to Home Screen, enable Open as Web App and tap Add. The site has an Apple home screen icon and uses an offline service worker.
